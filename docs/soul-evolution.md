# Soul Evolution 1.0

Foundational implementation of all ten requested tracks: natural dialogue guidance, gradual personality evolution, contextual emotional understanding, relationship continuity, confirmed shared experiences, heuristic self-review, distinct voice guidance, optional curiosity, stable identity and versioned growth timeline.

The system does **not** add Mood System or autonomous agents. No UI changes.

Runtime integration: the existing Cloud.ru chat prompt receives bounded personality and confirmed-experience context. Growth is **not automatic**: the store supports explicit, bounded feedback updates, rollback, persistence and forgetting, but no UI/API workflow for approvals yet. Quality warnings are deterministic heuristics; they do not fact-check model outputs or train model weights. The supplied PNG avatar is not committed.
