# Настройки Amayune — реализация и ограничения

В текущей ветке добавлено отдельное веб-приложение настроек, потому что исходный репозиторий не содержал фронтенд и backend.

## Запуск

`Project.bat` запускает `node server/index.mjs` через npm, а сервер слушает только 127.0.0.1 и назначенный порт. Внешний вид сохраняется в localStorage с ключом `amayune.appearance.v1`. Серверные параметры модели сохраняются атомарно в `data/cloudru-settings.json` с проверкой диапазонов и схемы.

Секрет Cloud.ru сохраняется отдельно как `data/cloudru-secret.dpapi.json` с использованием DPAPI CurrentUser на Windows. Сервер не принимает операции с ключами на других ОС; в дальнейшем можно подключить отдельные защищённые хранилища. Файл не коммитится. Ключ не возвращается в ответе. При загрузке ключ автоматически не проверяется и платные генерации не выполняются.

Cloud.ru: официальный API `https://foundation-models.api.cloud.ru/v1/models`, Bearer API key. Источник: https://cloud.ru/docs/foundation-models/ug/topics/api-ref__specs . Наличие модели и тарифов отражается по ответу API. Отсутствующие значения показываются как неизвестные.

## Реализовано

- Системная, светлая, тёмная, чёрно-золотая и пользовательская темы; цветовые акценты.
- Скругление, масштаб, шрифты, плотность, ширина бокового меню, тени, анимация.
- Мгновенное применение, localStorage, экспорт/импорт JSON и восстановление.
- Страница Cloud.ru, запись/удаление ключа в DPAPI, модели по API, параметры и сохранение.
- Локальный API с валидацией, ограничением Host и Origin, CSRF-заголовком, строгим HTTP health-check.
- Проверки схемы и сохранения в Node test.

## Требует следующей доработки и подтверждения

- Генерация запросов, реальная резервная модель и расход токенов ещё не реализованы — сервер сейчас лишь управляет настройками.
- Проверки доступности отдельных моделей и эмбеддингов с платными пробными запросами не реализованы.
- DPAPI необходимо испытать на Windows 10/11 с реальным пользовательским профилем.
- Полный accessibility/UI E2E, адаптация планшетов, безопасность обновления и все исходные 155 пунктов требуют отдельного аудита.
- Текущий токен для локального API доступен веб-странице; это защита от CSRF, а не полноценная аутентификация другого локального пользователя. Для многопользовательских и недоверенных рабочих станций потребуется усиление.
- Настройки не следует считать production-ready до успешного CI и функциональных Windows E2E.
